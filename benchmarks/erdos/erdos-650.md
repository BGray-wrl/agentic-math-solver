# Problem

Let $f(m)$ be such that if $A\subseteq \{1,\ldots,N\}$ has $\lvert A\rvert=m$ then every interval in $[1,\infty)$ of length $2N$ contains $\geq f(m)$ many distinct integers $b_1,\ldots,b_r$ where each $b_i$ is divisible by some $a_i\in A$, where $a_1,\ldots,a_r$ are distinct.

Estimate $f(m)$. In particular is it true that $f(m)\ll m^{1/2}$?

# Short Solution
Erd\H{o}s and Sar\'{a}nyi \cite{ErSa59} proved that $f(m)\gg m^{1/2}$.

The answer is yes - that $f(m)\ll m^{1/2}$ seems to have been first proved by Erd\H{o}s and Selfridge as described in \cite{Er78} (see also \cite{Er86c}), so it is unclear why Erd\H{o}s repeated the question as open in \cite{Er95c}. An alternative construction, generated by GPT 5.4 Pro (prompted by He, Li, and Tang) is available here. This latter proof in fact proves $f(m)\leq 2\lceil \sqrt{m}\rceil$, and establishes the stronger fact that\[f(st)\leq s+t\]for all integers $s,t\geq 1$.
