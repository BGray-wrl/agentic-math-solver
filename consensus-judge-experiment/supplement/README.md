# Supplementary materials — Cost-Effective Automated Judging of Natural-Language Mathematical Proofs

This package lets a reader regenerate every table and figure in the paper from the
raw per-instance judge scores, and inspect the protocol. It is self-contained: the
metric computations need only the Python standard library.

## Reproduce

```bash
cd code
python compute_metrics.py     # regenerates Tables 1-3, A1 + extended tables -> ../results/tables/
python make_plots.py          # regenerates the figures (needs matplotlib + numpy)
```

`compute_metrics.py` prints all tables and writes them to `results/tables/`. Point
estimates reproduce the paper exactly; bootstrap interval endpoints may differ by
~0.005 from the paper because they are recomputed with a fixed but different RNG seed.

## What backs each claim

| Paper element | Regenerated by | Reads |
|---|---|---|
| Table 1 (validation, n=200) | `compute_metrics.py` → `table1_validation.csv` | `consensus_analysis.csv`, `gemini_high_validation.json` |
| Table 2 (full benchmark, n=1000) | `compute_metrics.py` → `table2_full1000.csv` | `consensus_analysis.csv` + `remaining600_*.json` |
| Table 3 (run-to-run, 4 runs) | `compute_metrics.py` → `table3_runtorun.csv` | `consensus_analysis.csv` + `multi_seed/*.json` |
| Table A1 (Gemini default vs high) | `compute_metrics.py` → `tableA1_gemini_reasoning.csv` | `consensus_analysis.csv` (Gemini default), `gemini_high_validation.json` |
| Figures 1-5 | `make_plots.py` | `consensus_analysis.csv`, `full1000_metrics.csv` (+ table values) |
| Extended results (App. material) | `compute_metrics.py` → `ext_*.csv` | as above; see `EXTENDED_RESULTS.md` |
| Judge prompt | — | `prompt/judge_gt.md` |

`make_plots.py` emits the figures under the candidate names it was developed with;
the mapping to the paper's Figures 1-5 is in its header, and the shipped PDFs are in
`results/figures/`.

## Costs

Per-200-gradings cost (USD), measured as the sum of OpenRouter's reported `usage.cost`
over each run: GPT-OSS-120B \$0.32, DeepSeek-V4-Flash \$0.70, Gemma-4-31B \$0.71, cheap
consensus (trio) \$1.73, Gemini 3.1 Pro (high) \$28.61, Gemini 3.1 Pro (default) \$7.07,
Claude Opus 4.7 \$32.45. Cost is provider- and run-dependent; `compute_metrics.py` reads
these from a small documented constant rather than recomputing them.

## Data provenance and the benchmark

The judges grade **IMO-GradingBench** (Luong et al., 2025, *Towards Robust Mathematical
Reasoning*; arXiv:2511.01846). **We do not redistribute the benchmark.** The files here
contain only grading IDs, problem-source labels, the human grades we compared against, our
judges' integer scores, and the judges' *verdict* text (model output, which may quote
fragments of a candidate proof). To re-query the judges from scratch with the reference
runners you must obtain IMO-GradingBench yourself and place it as `gradingbench.csv`, and
set `OPENROUTER_API_KEY` in your environment.

## Notes for reviewers

- **Spearman, not Pearson.** The secondary correlation metric is Spearman ρ throughout
  (rank correlation suits the coarse {0,1,6,7} output). Consensus rows omit ρ ("—")
  because averaging the buckets yields intermediate values not comparable to single judges.
- **Cheap judges are multi-provider.** The open-weight judges are served through OpenRouter
  by a shifting pool of third-party providers at varying quantizations; `multi_seed/` and
  `ext_provider_mix.csv` document the resulting run-to-run variance and provider mix.
- **Scoring buckets.** Judges are instructed to output one of {0, 1, 6, 7}; the parser
  accepts any integer 0–7, and a handful (4 across all runs) of off-bucket scores occurred
  and are used as parsed.
- **Backfilled validation calls.** 15 cheap-judge calls were rate-limited on the original
  run; `trials_validation.jsonl` carries their final backfilled scores (flagged
  `backfill: true`, matching `consensus_analysis.csv` and the tables).
- The reference runners are provided for transparency; the tables and figures are fully
  reproducible from the per-instance data without any API access.
